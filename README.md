# anki_import

🇷🇺 Русский · [🇩🇪 Deutsch](README.de.md)

Скрипт импортирует заметки из Excel в Anki (через [AnkiConnect](https://ankiweb.net/shared/info/2055492159)) и озвучивает нужные поля с помощью **gTTS** или **edge-tts**. Подходит для изучения иностранных слов с примерами предложений (по умолчанию настроен на немецкий → русский).

## Возможности

- Импорт строк из Excel в колоду Anki; дубликаты определяются по ключевому полю и пропускаются.
- Автоматическое создание колоды и типа заметки (поля, шаблоны карточек и CSS берутся из `config.yaml`), если их ещё нет.
- Озвучка пустых аудио-полей: файлы загружаются в медиа Anki, в поле записывается `[sound:...]`.
- Два движка озвучки: `gtts` (по умолчанию) и `edge` (голоса Microsoft Edge).
- Параллельная озвучка, повторные попытки при сетевых ошибках, дисковый кеш `.mp3`, полоса загрузки (если установлен `tqdm`).
- Режим `--dry-run`: все проверки выполняются, но ничего не создаётся и не меняется.
- Сообщения в консоли на русском или немецком.

## Требования

- Python 3.8+
- Запущенный Anki с дополнительным модулем **AnkiConnect** (код `2055492159`)
- Интернет (для озвучки)

## Установка

```bash
git clone https://github.com/KonshinAV/anki_import.git
cd <папка-репозитория>
pip install -r requirements.txt
```

Зависимости:

| `requests` | запросы к AnkiConnect | да |

## Быстрый старт

1. Запустите Anki.
2. Проверьте настройки в `config.yaml` (колода, тип заметки, имя Excel-файла).
3. Запустите скрипт:
   ```bash
   python3 anki_import.py
   ```
   Если Excel-файл из конфига не существует, скрипт создаст его рядом с собой с шапкой из полей и завершится. Заполните файл и запустите скрипт снова.
4. Рекомендуется сначала проверить план без изменений:
   ```bash
   python3 anki_import.py --dry-run
   ```

## Примеры запуска

```bash
python3 anki_import.py                      # импорт + озвучка
python3 anki_import.py --lang de            # сообщения на немецком
python3 anki_import.py --dry-run            # ничего не менять, только показать план
python3 anki_import.py --engine edge        # озвучка через edge-tts
python3 anki_import.py --no-audio           # только импорт
python3 anki_import.py --audio-only         # только озвучка пустых аудио-полей
python3 anki_import.py --config my.yaml     # другой файл настроек
python3 anki_import.py -h                   # все параметры
```

## Параметры командной строки

Параметры перекрывают значения из `config.yaml`.

| Параметр | Описание |
|---|---|
| `--config` | файл конфигурации (по умолчанию `config.yaml` рядом со скриптом) |
| `--lang {ru,de}` | язык сообщений (`ui.language`) |
| `--file` | Excel-файл (`excel.file`) |
| `--sheet` | имя листа (`excel.sheet`) |
| `--deck` | колода (`anki.deck`) |
| `--model` | тип заметки (`anki.model`) |
| `--url` | URL AnkiConnect (`anki.url`) |
| `--engine {gtts,edge}` | движок озвучки (`audio.engine`) |
| `--voice` | голос для edge-tts (`audio.edge_voice`) |
| `--workers` | число параллельных запросов к TTS (`audio.workers`) |
| `--cache-dir` | временная папка для `.mp3` (`audio.cache_dir`) |
| `--keep-audio` | не удалять `.mp3` после выполнения (кеш) |
| `--dry-run` | ничего не менять, только показать план |
| `--no-audio` | не озвучивать |
| `--audio-only` | только озвучка, без импорта |
| `--new-only` | озвучивать только заметки, добавленные в этом запуске |
| `--overwrite-audio` | перезаписывать уже заполненные аудио-поля |
| `-v`, `--verbose` | подробный лог |

## Как это работает

1. **Проверка Anki.** Скрипт проверяет соединение, наличие колоды и типа заметки. Недостающее создаётся (в `--dry-run` только сообщается). Имена сравниваются без учёта регистра. Если тип заметки уже существует, он **не изменяется**; скрипт лишь предупреждает о полях из конфига, которых в нём нет.
2. **Импорт.** Строки Excel читаются с указанного листа; пустые строки пропускаются. Заметка добавляется, только если значение ключевого поля (`fields.key`) ещё не встречается в колоде (сравнение без HTML, `[sound:...]` и регистра).
3. **Озвучка.** Для заметок колоды, у которых аудио-поле пусто, а исходное текстовое поле заполнено, генерируется mp3. Одинаковые тексты озвучиваются один раз. Файл загружается в медиа Anki под именем `tts-<движок>-<хеш>.mp3`, а в поле записывается `[sound:...]`. Тексты, которые не удалось озвучить, будут обработаны при следующем запуске.
4. **Очистка.** Временная папка с `.mp3` удаляется, если не задано `audio.keep_files: true` или `--keep-audio`.

## Формат Excel

- Первая строка — шапка: названия колонок должны совпадать с именами полей (см. `fields.base` и `fields.sentences`).
- Колонок для аудио-полей не нужно: они заполняются автоматически.
- Пустая ячейка в ключевой колонке — строка пропускается.

Для конфигурации по умолчанию колонки такие:

```
base_de | full_de | audio_text_de | base_tr | s1_de | s1_tr | ... | s9_de | s9_tr
```

## Конфигурация (`config.yaml`)

Относительные пути считаются от папки скрипта.

| Секция | Параметры |
|---|---|
| `ui` | `language` — язык консоли и справки `-h`: `ru` или `de` (по умолчанию `de`) |
| `anki` | `url`, `deck` (`::` — вложенность), `model`, `timeout` |
| `excel` | `file`, `sheet` |
| `fields` | `key` — поле для поиска дубликатов; `base` — обычные поля (они же колонки Excel); `sentences` — список предложений |
| `note_type` | `css` и `cards` (имя, лицевая и обратная сторона шаблона); используется **только при создании** типа |
| `audio` | `engine`, `gtts_lang`, `edge_voice`, `workers`, `cache_dir`, `keep_files`, `main_source`, `main_dest` |
| `retry` | `attempts`, `delay` — повторы при сетевых ошибках |

### Предложения

Каждое предложение задаётся явно, имена полей любые:

```yaml
sentences:
  - { de: s1_de, tr: s1_tr, audio: s1_audio }
```

- `de` — поле с предложением (обязательно)
- `tr` — поле с переводом (обязательно)
- `audio` — поле для `[sound:...]` (необязательно; без него предложение не озвучивается)

Количество предложений равно числу элементов списка.

### Озвучка основного слова

`audio.main_source` — поле, текст которого озвучивается, `audio.main_dest` — поле, куда кладётся звук. По умолчанию: `audio_text_de` → `base_audio`.

### Тип заметки

Поля типа строятся автоматически: `fields.base` + `audio.main_dest` + для каждого предложения `de`, `tr` и `audio` (если указан). Все `{{поля}}` в шаблонах должны быть среди них, иначе скрипт остановится до создания типа.


## Типичные проблемы

- **Не удалось подключиться к AnkiConnect** — проверьте, что Anki запущен, AnkiConnect установлен, а `anki.url` указан верно (по умолчанию `http://localhost:8765`).
- **В типе нет полей из конфига** — существующий тип не изменяется; добавьте поля в Anki вручную или создайте новый тип, указав другое имя в `anki.model`.
- **Озвучка не удалась** — проверьте интернет; число параллельных запросов можно снизить через `--workers`, либо попробуйте `--engine edge`.
- **Хочется озвучить заново** — используйте `--overwrite-audio`.
